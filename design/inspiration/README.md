# UI inspiration

Reference images for the minimalist direction. Flat surfaces, no drop shadows, clear button hovers.

| File | Notes |
|------|-------|
| `bloomfi.png` | Pill buttons, large radius, color-block cards, no borders |
| `grid-cards.png` | White cards on subtle grid, typography hierarchy |
| `case-studies.png` | High-contrast cards, solid accent buttons |
| `indigosafe-dashboard.png` | Light dashboard, thin borders, soft fills |
| `a-quiet-moment.png` | Editorial type, flat CTA, lots of whitespace |
| `mastercard.png` | Bold type, solid black buttons, no decoration |
| `x-ray-editorial.png` | Muted palette, soft panels, editorial labels |
| `soundre-dark.png` | Edge-to-edge layout, corner navigation |
| `faq-accordion.png` | Two-column, divider rows, no boxes |
| `wegrow-hero.png` | Bold color blocks, asymmetric full-bleed |

**Our rules:** no shadows on cards/buttons; separation via background color; pill buttons with obvious hover darkening/fill; use full page width for tables and dashboards; narrow inner content only for essay reading.
